# RPA-Uipath-Programs
UiPath RPA Sequence Projects – A collection of Robotic Process Automation (RPA) workflows developed using UiPath Studio. Includes Excel and PowerPoint automation activities using Sequence workflows to automate repetitive tasks, process data, and improve productivity.

## Projects
- **Excel Grades Activity:** Reads student marks from Excel and calculates total, percentage and grade.
- **Excel to PowerPoint Activity:** Converts sales data from Excel into a PowerPoint report.
- **PowerPoint Certificates Activity:** Generates a PowerPoint certificate for each participant listed in Excel.

Each folder is a separate UiPath project. Open its `project.json` in UiPath Studio to run it.
